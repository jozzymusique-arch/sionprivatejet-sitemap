# SionPrivateJet independent sitemap

This repository hosts the independent canonical sitemap for SionPrivateJet.com. Its authoritative inventory currently contains 40 canonical, indexable URLs.

Hostinger AI Builder's native root sitemap currently exposes only static pages. This repository provides a Google discovery mitigation; it does not replace the Hostinger root `/sitemap.xml`.

Intended public sitemap URL: https://sitemaps.sionprivatejet.com/sitemap.xml
